<div id="welcome-to-firecrawl">
  ## Bienvenido a Firecrawl
</div>

[Firecrawl](https://firecrawl.dev?ref=github) es un servicio de API que toma una URL, la rastrea y la convierte en Markdown limpio. Rastrearemos todas las subpáginas accesibles y te entregaremos Markdown limpio para cada una. No se requiere sitemap.

<div id="how-to-use-it">
  ## ¿Cómo usarlo?
</div>

<div id="features">
  ### Funcionalidades
</div>

* [**Scrape**](#scraping): extrae una URL y obtiene su contenido en un formato listo para LLM (markdown, resumen, datos estructurados vía [modo JSON](#json-mode), captura de pantalla, HTML)
* [**Crawl**](#crawling): recorre todas las URL de una página web y devuelve el contenido en un formato listo para LLM
* [**Map**](/es/features/map): ingresa un sitio web y obtén todas sus URL; extremadamente rápido
* [**Search**](/es/features/search): busca en la web y obtiene el contenido completo de los resultados
* [**Extract**](/es/features/extract): obtiene datos estructurados de una sola página, varias páginas o sitios web completos con IA.

<div id="powerful-capabilities">
  ### Capacidades potentes
</div>

* **Formatos listos para LLM**: Markdown, resumen, datos estructurados, captura de pantalla, HTML, enlaces, metadatos
* **Lo difícil**: proxies, mecanismos antibot, contenido dinámico (renderizado con JS), análisis del resultado, orquestación
* **Ultrarrápido**: Obtén resultados en segundos: diseñado para la velocidad y casos de alto rendimiento.
* **Personalización**: excludeTags, rastreo detrás de muros de autenticación con headers personalizados, profundidad máxima de rastreo, etc.
* **Análisis de medios**: PDFs, DOCX, imágenes.
* **Fiabilidad ante todo**: diseñado para obtener los datos que necesitas, sin importar lo difícil que sea.
* **Acciones**: click, scroll, input, wait y más antes de extraer datos

Puedes encontrar todas las capacidades de Firecrawl y cómo usarlas en nuestra [documentación](https://docs.firecrawl.dev/api-reference/v2-introduction)

<div id="open-source-vs-cloud">
  ## Código abierto vs nube
</div>

Firecrawl es de código abierto y está disponible bajo la [licencia AGPL-3.0](https://github.com/mendableai/firecrawl/blob/main/LICENSE).

Para ofrecer el mejor producto posible, proporcionamos una versión alojada de Firecrawl junto con nuestra oferta de código abierto. La solución en la nube nos permite innovar de forma continua y mantener un servicio de alta calidad y sostenible para todos los usuarios.

Firecrawl Cloud está disponible en [firecrawl.dev](https://firecrawl.dev) y ofrece un conjunto de funciones que no están disponibles en la versión de código abierto:
