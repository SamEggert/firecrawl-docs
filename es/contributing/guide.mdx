¡Bienvenido a [Firecrawl](https://firecrawl.dev) 🔥! Aquí tienes instrucciones para obtener el proyecto en local, de modo que puedas ejecutarlo por tu cuenta (y contribuir).

Si vas a contribuir, ten en cuenta que el proceso es similar al de otros repositorios de código abierto (haz un fork de Firecrawl, realiza cambios, ejecuta las pruebas, abre un PR). Si tienes alguna pregunta y necesitas ayuda para empezar, escribe a help@firecrawl.com o abre un issue.

<div id="running-the-project-locally">
  ## Ejecutar el proyecto localmente
</div>

Primero, instala las dependencias:

1. Node.js [instrucciones](https://nodejs.org/en/learn/getting-started/how-to-install-nodejs)
2. pnpm [instrucciones](https://pnpm.io/installation)
3. Redis [instrucciones](https://redis.io/docs/latest/operate/oss_and_stack/install/install-redis/)
4. PostgreSQL
5. Docker (opcional) (para ejecutar Postgres)

Debes configurar la base de datos de PostgreSQL ejecutando el archivo SQL en `apps/nuq-postgres/nuq.sql`. La forma más sencilla es usar la imagen de Docker dentro de `apps/nuq-postgres`. Con Docker en ejecución, compila la imagen:

```bash
docker build -t nuq-postgres .
```

y después ejecuta:

```bash
docker run --name nuqdb \          
  -e POSTGRES_PASSWORD=postgres \
  -p 5433:5432 \
  -v nuq-data:/var/lib/postgresql/data \
  -d nuq-postgres
```

Configura las variables de entorno en un archivo .env en el directorio /apps/api/; puedes copiar la plantilla de .env.example.

Para empezar, no configuraremos la autenticación ni ningún subservicio opcional (análisis de PDF, bloqueo de JS, funciones de IA).

.env:

```
# ===== ENVS requeridas ======
NUM_WORKERS_PER_QUEUE=8
PORT=3002
HOST=0.0.0.0
REDIS_URL=redis://localhost:6379
REDIS_RATE_LIMIT_URL=redis://localhost:6379

## Para habilitar la autenticación de BD, debes configurar Supabase.
USE_DB_AUTHENTICATION=false

## Usar PostgreSQL para la cola: cambia si las credenciales, el host o la BD son diferentes
NUQ_DATABASE_URL=postgres://postgres:postgres@localhost:5433/postgres

# ===== ENVS opcionales ======

# Configuración de Supabase (se usa para habilitar autenticación de BD, registro avanzado, etc.)
SUPABASE_ANON_TOKEN=
SUPABASE_URL=
SUPABASE_SERVICE_TOKEN=

# Otros opcionales
TEST_API_KEY= # úsala si configuraste autenticación y quieres probar con una clave de API real
OPENAI_API_KEY= # agrega para funciones que dependen de LLM (generación de texto alternativo de imagen, etc.)
BULL_AUTH_KEY= @
PLAYWRIGHT_MICROSERVICE_URL=  # establece si quieres ejecutar un fallback de Playwright
LLAMAPARSE_API_KEY= # establece si tienes una clave de Llamaparse que quieras usar para analizar PDFs
SLACK_WEBHOOK_URL= # establece si quieres enviar mensajes de estado del servidor a Slack
POSTHOG_API_KEY= # establece si quieres enviar eventos de PostHog como registros de tareas
POSTHOG_HOST= # establece si quieres enviar eventos de PostHog como registros de tareas


```


<div id="installing-dependencies">
  ### Instalación de dependencias
</div>

Primero, instala las dependencias con pnpm.

```bash
# cd apps/api # para asegurarte de que estás en la carpeta correcta
pnpm install # asegúrate de tener pnpm versión 9 o superior
```


<div id="running-the-project">
  ### Ejecutar el proyecto
</div>

Necesitarás abrir 3 terminales.

<div id="terminal-1-setting-up-redis">
  ### Terminal 1 - configuración de Redis
</div>

Ejecuta el comando en cualquier parte de tu proyecto

```bash
redis-server
```


<div id="terminal-2-setting-up-the-service">
  ### Terminal 2 - configuración del servicio
</div>

Ahora, ve al directorio apps/api/ y ejecuta:

```bash
pnpm start
# si vas a usar la [funcionalidad llm-extract](https://github.com/firecrawl/firecrawl/pull/586/), también debes exportar OPENAI_API_KEY=sk-______
```

Esto iniciará los workers responsables de procesar los trabajos de rastreo.


<div id="terminal-3-sending-our-first-request">
  ### Terminal 3: enviando nuestra primera solicitud.
</div>

Bien, ahora enviemos nuestra primera solicitud.

```curl
curl -X GET http://localhost:3002/test
```

Esto debería devolver la respuesta «Hello, world!»

Si quieres probar el endpoint de crawl, puedes ejecutar lo siguiente

```curl
curl -X POST http://localhost:3002/v1/crawl \
    -H 'Content-Type: application/json' \
    -d '{
      "url": "https://mendable.ai"
    }'
```


<div id="alternative-using-docker-compose">
  ### Alternativa: usar Docker Compose
</div>

Para una configuración más sencilla, puedes usar Docker Compose para ejecutar todos los servicios:

1. Requisitos previos: asegúrate de tener Docker y Docker Compose instalados
2. Copia el archivo `.env.example` a `.env` en el directorio `/apps/api/` y configúralo según sea necesario
3. Desde el directorio raíz, ejecuta:

```bash
docker compose up
```

Esto iniciará Redis, el servidor de la API y los workers automáticamente con la configuración adecuada.
