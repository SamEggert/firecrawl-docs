<div id="inline-code">
  ### Código en línea
</div>

Para indicar una `palabra` o `frase` como código, enciérrala entre acentos graves (`).

```
Para indicar una `palabra` o `frase` como código, enciérrala entre comillas invertidas (`).
```


<div id="code-block">
  ### Bloque de código
</div>

Usa [bloques de código con cerco](https://www.markdownguide.org/extended-syntax/#fenced-code-blocks) encerrando el código entre tres acentos invertidos (```) y, a continuación, indica el lenguaje de programación del fragmento para obtener resaltado de sintaxis. De forma opcional, también puedes escribir el nombre del fragmento después del lenguaje de programación.

```java HolaMundo.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("¡Hola, mundo!");
    }
}
```
