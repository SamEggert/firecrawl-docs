El menú de navegación es la lista de enlaces presente en todo sitio web.

Seguramente tendrás que actualizar `mint.json` cada vez que agregues una página nueva. Las páginas no aparecen automáticamente.

<div id="navigation-syntax">
  ## Sintaxis de navegación
</div>

Nuestra sintaxis de navegación es recursiva, lo que significa que puedes crear grupos de navegación anidados. No necesitas incluir `.mdx` en los nombres de las páginas.

<CodeGroup>

```json Regular Navigation
"navigation": [
    {
        "group": "Getting Started",
        "pages": ["quickstart"]
    }
]
```

```json Nested Navigation
"navigation": [
    {
        "group": "Getting Started",
        "pages": [
            "quickstart",
            {
                "group": "Nested Reference Pages",
                "pages": ["nested-reference-page"]
            }
        ]
    }
]
```

</CodeGroup>

<div id="folders">
  ## Carpetas
</div>

Simplemente coloca tus archivos MDX en carpetas y actualiza las rutas en `mint.json`.

Por ejemplo, para tener una página en `https://yoursite.com/your-folder/your-page`, crearías una carpeta llamada `your-folder` que contenga un archivo MDX llamado `your-page.mdx`.

<Warning>
  No puedes usar `api` como nombre de carpeta a menos que la anides dentro de otra. Mintlify usa Next.js, que reserva la carpeta `api` en el nivel superior para llamadas internas del servidor. Un nombre de carpeta como `api-reference` sería válido.
</Warning>

```json Navegación con carpeta
"navigation": [
    {
        "group": "Nombre del grupo",
        "pages": ["your-folder/your-page"]
    }
]
```


<div id="hidden-pages">
  ## Páginas ocultas
</div>

Los archivos MDX que no estén incluidos en `mint.json` no aparecerán en la barra lateral, pero serán accesibles desde la barra de búsqueda o mediante un enlace directo.
