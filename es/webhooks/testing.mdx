Esta página presenta herramientas y técnicas para probar integraciones de webhooks durante el desarrollo y para depurar problemas en producción.

<div id="local-development">
  ## Desarrollo local
</div>

<div id="exposing-local-servers">
  ### Exponer servidores locales
</div>

Como los webhooks deben poder acceder a tu servidor desde Internet, tendrás que exponer públicamente tu servidor de desarrollo local.

<div id="using-cloudflare-tunnels">
  #### Uso de Cloudflare Tunnels
</div>

[Cloudflare Tunnels](https://github.com/cloudflare/cloudflared/releases) ofrece una forma gratuita de exponer de manera segura tu servidor de desarrollo local a Internet, sin necesidad de registrar una cuenta ni abrir puertos en el firewall:

```bash
# Descarga cloudflared desde las publicaciones de GitHub o usa un gestor de paquetes

# Expón tu servidor local
cloudflared tunnel --url localhost:3000

# Ejemplo de salida:
# ¡Se ha creado tu túnel rápido! Accede a él en (puede tardar un poco en estar disponible):
# https://abc123.trycloudflare.com
```

Usa la URL proporcionada en la configuración del webhook:

```json
{
  "url": "https://abc123.trycloudflare.com/webhook"
}
```


<div id="debugging-common-issues">
  ## Depuración de problemas comunes
</div>

<div id="webhooks-not-arriving">
  ### Los webhooks no llegan
</div>

1. **Comprueba la accesibilidad de la URL** – Asegúrate de que tu endpoint sea accesible públicamente
2. **Verifica HTTPS** – Las URL de los webhooks deben usar HTTPS
3. **Revisa la configuración del firewall** – Permite conexiones entrantes al puerto de tu webhook
4. **Revisa los filtros de eventos** – Asegúrate de estar suscrito a los tipos de evento correctos

<div id="signature-verification-failing">
  ### Error en la verificación de la firma
</div>

1. **Comprueba la clave secreta** – Asegúrate de que estás usando la clave correcta

2. **Verifica el uso del cuerpo sin procesar** – Asegúrate de estar usando el cuerpo de la solicitud en bruto (raw):

```javascript
// ❌ Incorrecto: usando el cuerpo analizado
const signature = crypto
  .createHmac('sha256', secret)
  .update(JSON.stringify(req.body))
  .digest('hex');

// ✅ Correcto: usando el cuerpo en bruto
app.use('/webhook', express.raw({ type: 'application/json' }));
app.post('/webhook', (req, res) => {
  const signature = crypto
    .createHmac('sha256', secret)
    .update(req.body) // Búfer en bruto
    .digest('hex');
});
```
