Una implementación de servidor del Model Context Protocol (MCP) que integra [Firecrawl](https://github.com/mendableai/firecrawl) para ofrecer capacidades de scraping web. Nuestro servidor MCP es de código abierto y está disponible en [GitHub](https://github.com/mendableai/firecrawl-mcp-server).

<div id="features">
  ## Funcionalidades
</div>

- Raspado web, rastreo y descubrimiento
- Búsqueda y extracción de contenido
- Investigación en profundidad y raspado por lotes
- Compatibilidad en la nube y autoservicio
- Compatibilidad con SSE

<div id="installation">
  ## Instalación
</div>

Puedes usar nuestra URL alojada de forma remota o ejecutar el servidor localmente. Obtén tu clave de API en [https://firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys)

  ### URL alojada remotamente
</div>

```bash
https://mcp.firecrawl.dev/{FIRECRAWL_API_KEY}/v2/sse
```

  #### Instalación manual

Configuración de Cursor 🖥️
Nota: Requiere Cursor versión 0.45.6 o superior.
Para obtener las instrucciones de configuración más recientes, consulta la documentación oficial de Cursor sobre cómo configurar servidores MCP:
[Guía de configuración de servidores MCP de Cursor](https://docs.cursor.com/context/model-context-protocol#configuring-mcp-servers)

Para configurar Firecrawl MCP en Cursor **v0.48.6**

1. Abre la configuración de Cursor.
2. Ve a Features > MCP Servers.
3. Haz clic en "+ Add new global MCP server".
4. Ingresa el siguiente código:
   ```json
   {
     "mcpServers": {
       "firecrawl-mcp": {
         "command": "npx",
         "args": ["-y", "firecrawl-mcp"],
         "env": {
           "FIRECRAWL_API_KEY": "YOUR-API-KEY"
         }
       }
     }
   }
   ```

Para configurar Firecrawl MCP en Cursor **v0.45.6**

1. Abre la configuración de Cursor.
2. Ve a Features > MCP Servers.
3. Haz clic en "+ Add New MCP Server".
4. Ingresa lo siguiente:
   - Name: "firecrawl-mcp" (o el nombre que prefieras)
   - Type: "command"
   - Command: `env FIRECRAWL_API_KEY=your-api-key npx -y firecrawl-mcp`

> Si usas Windows y tienes problemas, prueba `cmd /c "set FIRECRAWL_API_KEY=your-api-key && npx -y firecrawl-mcp"`

Reemplaza `your-api-key` con tu clave de API de Firecrawl. Si aún no tienes una, puedes crear una cuenta y obtenerla en https://www.firecrawl.dev/app/api-keys

Después de agregarlo, actualiza la lista de servidores MCP para ver las nuevas herramientas. El Composer Agent usará automáticamente Firecrawl MCP cuando corresponda, pero también puedes solicitarlo explícitamente describiendo tus necesidades de web scraping. Accede al Composer con Command+L (Mac), selecciona "Agent" junto al botón de enviar e ingresa tu consulta.

<div id="environment-variables">
  ### Variables de entorno
</div>

<div id="required-for-cloud-api">
  #### Requerido para la API en la nube
</div>

- `FIRECRAWL_API_KEY`: Tu clave de API de Firecrawl
  - Obligatorio al usar la API en la nube (por defecto)
  - Opcional si usas una instancia autohospedada con `FIRECRAWL_API_URL`
- `FIRECRAWL_API_URL` (opcional): Endpoint de API personalizado para instancias autohospedadas
  - Ejemplo: `https://firecrawl.your-domain.com`
  - Si no se proporciona, se usará la API en la nube (requiere clave de API)

<div id="optional-configuration">
  #### Configuración opcional
</div>

<div id="retry-configuration">
  ##### Configuración de reintentos
</div>

- `FIRECRAWL_RETRY_MAX_ATTEMPTS`: Número máximo de reintentos (predeterminado: 3)
- `FIRECRAWL_RETRY_INITIAL_DELAY`: Espera inicial en milisegundos antes del primer reintento (predeterminado: 1000)
- `FIRECRAWL_RETRY_MAX_DELAY`: Espera máxima en milisegundos entre reintentos (predeterminado: 10000)
- `FIRECRAWL_RETRY_BACKOFF_FACTOR`: Factor de backoff exponencial (predeterminado: 2)

<div id="credit-usage-monitoring">
  ##### Monitoreo del uso de créditos
</div>

- `FIRECRAWL_CREDIT_WARNING_THRESHOLD`: Umbral de advertencia para el uso de créditos (por defecto: 1000)
- `FIRECRAWL_CREDIT_CRITICAL_THRESHOLD`: Umbral crítico para el uso de créditos (por defecto: 100)

<div id="configuration-examples">
  ### Ejemplos de configuración
</div>

Para usar la API en la nube con reintentos personalizados y control de créditos:

```bash
# Requerido para la API en la nube
export FIRECRAWL_API_KEY=your-api-key

# Configuración opcional de reintentos
export FIRECRAWL_RETRY_MAX_ATTEMPTS=5        # Aumenta el número máximo de reintentos
export FIRECRAWL_RETRY_INITIAL_DELAY=2000    # Comienza con un retraso de 2 s
export FIRECRAWL_RETRY_MAX_DELAY=30000       # Retraso máximo de 30 s
export FIRECRAWL_RETRY_BACKOFF_FACTOR=3      # Backoff más agresivo

# Supervisión opcional de créditos
export FIRECRAWL_CREDIT_WARNING_THRESHOLD=2000    # Advertencia a los 2000 créditos
export FIRECRAWL_CREDIT_CRITICAL_THRESHOLD=500    # Crítico a los 500 créditos
```

Para instancias autogestionadas:

```bash
# Requerido para instalaciones autogestionadas (self-hosted)
export FIRECRAWL_API_URL=https://firecrawl.tu-dominio.com

# Autenticación opcional para instalaciones autogestionadas (self-hosted)
export FIRECRAWL_API_KEY=your-api-key  # Si tu instancia requiere autenticación

# Configuración personalizada de reintentos
export FIRECRAWL_RETRY_MAX_ATTEMPTS=10
export FIRECRAWL_RETRY_INITIAL_DELAY=500     # Comienza con reintentos más rápidos
```

<div id="system-configuration">
  ### Configuración del sistema
</div>

El servidor incluye varios parámetros configurables que se pueden definir mediante variables de entorno. Estos son los valores predeterminados si no se especifican:

```typescript
const CONFIG = {
  retry: {
    maxAttempts: 3, // Número de reintentos para solicitudes limitadas por límites de velocidad
    initialDelay: 1000, // Retraso inicial antes del primer reintento (en milisegundos)
    maxDelay: 10000, // Retraso máximo entre reintentos (en milisegundos)
    backoffFactor: 2, // Multiplicador para el backoff exponencial
  },
  credit: {
    warningThreshold: 1000, // Avisar cuando el uso de crédito alcance este nivel
    criticalThreshold: 100, // Alerta crítica cuando el uso de crédito alcance este nivel
  },
};
```

Estas configuraciones controlan:

1. **Comportamiento de reintento**

   * Reintenta automáticamente las solicitudes fallidas debido a límites de velocidad
   * Usa backoff exponencial para evitar sobrecargar la API
   * Ejemplo: Con la configuración predeterminada, los reintentos se realizarán en:
     * 1.er reintento: 1 segundo de espera
     * 2.º reintento: 2 segundos de espera
     * 3.er reintento: 4 segundos de espera (con tope en maxDelay)

2. **Monitoreo del uso de créditos**
   * Supervisa el consumo de créditos de la API en la nube
   * Emite avisos en umbrales específicos
   * Ayuda a prevenir interrupciones inesperadas del servicio
   * Ejemplo: Con la configuración predeterminada:
     * Aviso con 1000 créditos restantes
     * Alerta crítica con 100 créditos restantes


<div id="rate-limiting-and-batch-processing">
  ### Límites de velocidad y procesamiento por lotes
</div>

El servidor utiliza las capacidades integradas de Firecrawl para los límites de velocidad y el procesamiento por lotes:

- Gestión automática de límites de velocidad con backoff exponencial
- Procesamiento paralelo eficiente para operaciones por lotes
- Encolado y limitación inteligente de solicitudes
- Reintentos automáticos ante errores transitorios

<div id="1-scrape-tool-firecrawl_scrape">
  ### 1. Herramienta de raspado (`firecrawl_scrape`)
</div>

Extrae contenido de una única URL con opciones avanzadas.

```json
{
  "name": "firecrawl_scrape",
  "arguments": {
    "url": "https://example.com",
    "formats": ["markdown"],
    "onlyMainContent": true,
    "waitFor": 1000,
    "timeout": 30000,
    "mobile": false,
    "includeTags": ["article", "main"],
    "excludeTags": ["nav", "footer"],
    "skipTlsVerification": false
  }
}
```


<div id="2-batch-scrape-tool-firecrawl_batch_scrape">
  ### 2. Herramienta de Raspado por lotes (`firecrawl_batch_scrape`)
</div>

Raspa múltiples URL de forma eficiente con límites de velocidad integrados y procesamiento en paralelo.

```json
{
  "name": "firecrawl_batch_scrape",
  "arguments": {
    "urls": ["https://example1.com", "https://example2.com"],
    "options": {
      "formats": ["markdown"],
      "soloContenidoPrincipal": true
    }
  }
}
```

La respuesta incluye el ID de la operación para comprobar el estado:

```json
{
  "content": [
    {
      "type": "text",
      "text": "Operación por lotes encolada con ID: batch_1. Usa firecrawl_check_batch_status para consultar el progreso."
    }
  ],
  "isError": false
}
```


<div id="3-check-batch-status-firecrawl_check_batch_status">
  ### 3. Comprobar el estado del lote (`firecrawl_check_batch_status`)

<div id="6-extract-tool-firecrawl_extract">
  ### 6. Herramienta de extracción (`firecrawl_extract`)
</div>

Extrae información estructurada de páginas web usando capacidades de LLM. Compatible tanto con IA en la nube como con extracción mediante LLM autoalojados.

```json
{
  "name": "firecrawl_extract",
  "arguments": {
    "urls": ["https://example.com/page1", "https://example.com/page2"],
    "prompt": "Extrae la información del producto, incluidos el nombre, el precio y la descripción",
    "systemPrompt": "Eres un asistente útil que extrae información de productos",
    "schema": {
      "type": "object",
      "properties": {
        "name": { "type": "string" },
        "price": { "type": "number" },
        "description": { "type": "string" }
      },
      "required": ["name", "price"]
    },
    "allowExternalLinks": false,
    "enableWebSearch": false,
    "includeSubdomains": false
  }
}
```

Ejemplo de respuesta:

```json
{
  "content": [
    {
      "type": "text",
      "text": {
        "name": "Producto de ejemplo",
        "price": 99.99,
        "description": "Descripción de producto de ejemplo"
      }
    }
  ],
  "isError": false
}
```


<div id="extract-tool-options">
  #### Opciones de la herramienta Extract:
</div>

- `urls`: Lista de URLs de las que extraer información
- `prompt`: Prompt personalizado para la extracción con el LLM
- `systemPrompt`: Prompt del sistema para guiar al LLM
- `schema`: Esquema JSON para extraer datos estructurados
- `allowExternalLinks`: Permitir la extracción desde enlaces externos
- `enableWebSearch`: Habilitar la búsqueda web para obtener contexto adicional
- `includeSubdomains`: Incluir subdominios en la extracción

Al usar una instancia autoalojada, la extracción utilizará tu LLM configurado. En la API en la nube, se usa el servicio de LLM gestionado de Firecrawl.

### 7. Herramienta de investigación profunda (firecrawl&#95;deep&#95;research)

Realiza una investigación web en profundidad sobre una consulta mediante rastreo inteligente, búsqueda y análisis con LLM.

```json
{
  "name": "firecrawl_deep_research",
  "arguments": {
    "query": "¿Cómo funciona la tecnología de captura de carbono?",
    "maxDepth": 3,
    "timeLimit": 120,
    "maxUrls": 50
  }
}
```

Argumentos:

* query (string, obligatorio): La pregunta de investigación o el tema a explorar.
* maxDepth (number, opcional): Profundidad máxima de recursión para el rastreo/búsqueda (valor predeterminado: 3).
* timeLimit (number, opcional): Límite de tiempo en segundos para la sesión de investigación (valor predeterminado: 120).
* maxUrls (number, opcional): Número máximo de URL a analizar (valor predeterminado: 50).

Devuelve:

* Análisis final generado por un LLM a partir de la investigación. (data.finalAnalysis)
* También puede incluir actividades estructuradas y las fuentes utilizadas durante el proceso de investigación.


### 8. Generar la herramienta LLMs.txt (firecrawl&#95;generate&#95;llmstxt)

Genera un archivo llms.txt estandarizado (y, opcionalmente, llms-full.txt) para un dominio específico. Este archivo define cómo deben interactuar los modelos de lenguaje de gran tamaño con el sitio.

```json
{
  "name": "firecrawl_generate_llmstxt",
  "arguments": {
    "url": "https://example.com",
    "maxUrls": 20,
    "showFullText": true
  }
}
```

Argumentos:

* url (string, requerido): La URL base del sitio web a analizar.
* maxUrls (number, opcional): Número máximo de URL a incluir (predeterminado: 10).
* showFullText (boolean, opcional): Indica si se debe incluir el contenido de llms-full.txt en la respuesta.

Devuelve:

* Contenido generado del archivo llms.txt y, opcionalmente, de llms-full.txt (data.llmstxt y/o data.llmsfulltxt)
