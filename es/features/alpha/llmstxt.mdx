<div id="introducing-llmstxt-generator-endpoint-alpha">
  ## Presentamos el endpoint generador de LLMs.txt (Alpha) 📃
</div>

El endpoint `/llmstxt` te permite transformar cualquier sitio web en [archivos de texto limpios y listos para LLM](https://www.firecrawl.dev/blog/How-to-Create-an-llms-txt-File-for-Any-Website). Solo tienes que proporcionar una URL, y Firecrawl rastreará el sitio y generará los archivos `llms.txt` y `llms-full.txt`, que pueden utilizarse para entrenamiento o análisis con cualquier LLM.

<div id="how-it-works">
  ## Cómo funciona
</div>

El generador de LLMs.txt:

1. Rastrea la URL del sitio web proporcionada y sus páginas vinculadas
2. Extrae texto limpio y significativo
3. Genera dos formatos:
   * `llms.txt`: Resúmenes concisos e información clave
   * `llms-full.txt`: Texto completo con más detalle

**Parámetros principales:**

* **url**: URL del sitio web del que generar los archivos LLMs.txt
* **maxUrls** (opcional): Número máximo de páginas a rastrear (1–100; valor predeterminado: 10)
* **showFullText** (opcional): Genera llms-full.txt además de llms.txt (valor predeterminado: false)

Consulta la [referencia de la API](/es/api-reference/endpoint/llmstxt) para más detalles.

<div id="known-limitations-alpha">
  ## Limitaciones conocidas (Alpha)
</div>

1. **Restricciones de acceso**\
   Solo se pueden procesar páginas de acceso público. El contenido protegido con inicio de sesión o con muro de pago no es compatible.

2. **Tamaño del sitio**\
   Durante la etapa alpha, solo permitimos procesar hasta 5000 URL.

3. **Estado Alpha**\
   Como función en Alpha, el formato de salida y el procesamiento pueden evolucionar según la retroalimentación.

<div id="billing-and-usage">
  ## Facturación y uso
</div>

La facturación se basa en la cantidad de URL procesadas:

* Costo base: 1 crédito por URL procesada
* Controla los costos de URL con el parámetro `maxUrls`
