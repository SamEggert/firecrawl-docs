Firecrawl ofrece distintos tipos de proxy para ayudarte a extraer datos de sitios web con diversos niveles de protección antibots. El tipo de proxy puede especificarse mediante el parámetro `proxy`.


<div id="proxy-types">
  ### Tipos de proxy
</div>

Firecrawl admite tres tipos de proxy:

- **basic**: Proxies para extraer datos de sitios con soluciones anti-bot nulas o básicas. Rápidos y generalmente funcionan.
- **stealth**: Proxies sigilosos para extraer datos de sitios con soluciones anti-bot avanzadas. Más lentos, pero más confiables en ciertos sitios.
- **auto**: Firecrawl reintentará automáticamente la extracción con proxies sigilosos si falla el proxy básico. Si el reintento con stealth tiene éxito, se facturarán 5 créditos por la extracción. Si el primer intento con basic tiene éxito, solo se cobrará el costo regular.

Si no especificas un proxy, Firecrawl usará auto por defecto.
