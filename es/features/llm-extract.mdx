<div id="scrape-and-extract-structured-data-with-firecrawl">
  ## Extrae y estructura datos con Firecrawl
</div>

Firecrawl usa IA para obtener datos estructurados de páginas web en 3 pasos:

1. **Configura el esquema (opcional):**
   Define un esquema JSON (usando el formato de OpenAI) para especificar los datos que necesitas, o simplemente proporciona un `prompt` si no requieres un esquema estricto, junto con la URL de la página.

2. **Realiza la solicitud:**
   Envía tu URL y el esquema a nuestro endpoint de raspado usando el modo JSON. Consulta cómo hacerlo aquí:
   [Documentación del endpoint de raspado](https://docs.firecrawl.dev/api-reference/endpoint/scrape)

3. **Obtén tus datos:**
   Recibe datos limpios y estructurados que se ajustan a tu esquema y que puedes usar de inmediato.

Esto hace que obtener datos web en el formato que necesitas sea rápido y sencillo.

<div id="json-format-options">
  ### Opciones de formato JSON
</div>

Al usar el modo JSON, incluye un objeto en `formats`, por ejemplo:

`formats: [{ type: 'json', schema: { ... }, prompt: '...' }]`

Parámetros:

- `schema`: JSON Schema que describe la salida estructurada que quieres.
- `prompt`: Solicitud opcional para guiar la extracción (también se usa para la extracción sin esquema).
