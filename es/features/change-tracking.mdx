![Seguimiento de cambios](/images/launch-week/lw3d12.webp)

El seguimiento de cambios te permite supervisar y detectar variaciones en el contenido web a lo largo del tiempo. Esta función está disponible en los SDK de JavaScript y Python.

<div id="overview">
  ## Descripción general
</div>

El Seguimiento de cambios te permite:

- Detectar si una página web ha cambiado desde el último raspado
- Ver los cambios específicos entre raspados
- Obtener datos estructurados sobre lo que ha cambiado
- Controlar la visibilidad de los cambios

Usando el formato `changeTracking`, puedes monitorear cambios en un sitio web y recibir información sobre:

- `previousScrapeAt`: La marca de tiempo del raspado anterior con el que se compara la página actual (`null` si no hubo raspado previo)
- `changeStatus`: El resultado de la comparación entre las dos versiones de la página
  - `new`: Esta página no existía o no se había descubierto antes (generalmente tiene `previousScrapeAt` en `null`)
  - `same`: El contenido de esta página no ha cambiado desde el último raspado
  - `changed`: El contenido de esta página ha cambiado desde el último raspado
  - `removed`: Esta página se eliminó desde el último raspado
- `visibility`: La visibilidad de la página/URL actual
  - `visible`: Esta página es visible, lo que significa que su URL se descubrió por una ruta orgánica (a través de enlaces en otras páginas visibles o del sitemap)
  - `hidden`: Esta página no es visible, lo que significa que sigue disponible en la web, pero ya no es detectable mediante el sitemap o el rastreo del sitio. Solo podemos identificar enlaces no visibles si antes habían sido visibles y se capturaron durante un rastreo o raspado previos

<div id="basic-usage">
  ### Uso básico
</div>

Para utilizar el seguimiento de cambios, incluye `'changeTracking'` en los formatos al raspar una URL:

<CodeGroup>
  ```js Node
  const firecrawl = new Firecrawl({ apiKey: 'your-api-key' });
  const result = await firecrawl.scrape('https://example.com', {
    formats: ['markdown', 'changeTracking']
  });

  // Acceder a los datos de seguimiento de cambios
  console.log(result.changeTracking)
  ```

  ```python Python
  from firecrawl import Firecrawl
  from pydantic import BaseModel

  firecrawl = Firecrawl(api_key='your-api-key')
  result = firecrawl.scrape('https://example.com',
      formats=['markdown', 'change_tracking']
  )

  # Acceder a los datos de seguimiento de cambios
  print("Seguimiento de cambios:", result.change_tracking)
  ```
</CodeGroup>

Ejemplo de respuesta:

```json
{
  "url": "https://firecrawl.dev",
  "markdown": "# Agentes de IA para ofrecer experiencias excepcionales al cliente\n\nChatbots que encantan a tus usuarios...",
  "changeTracking": {
    "previousScrapeAt": "2025-04-10T12:00:00Z",
    "changeStatus": "modificado",
    "visibility": "visible"
  }
}
```


<div id="advanced-options">
  ### Opciones avanzadas
</div>

Puedes configurar el seguimiento de cambios pasando un objeto en el array `formats`:

<CodeGroup>

```js Node
const result = await firecrawl.scrape('https://example.com', {
  formats: [
    'markdown',
    {
      type: 'changeTracking',
      modes: ['git-diff', 'json'], // Habilita modos específicos de seguimiento de cambios
      schema: {
        type: 'object',
        properties: {
          title: { type: 'string' },
          content: { type: 'string' }
        }
      }, // Esquema para la comparación de JSON estructurado
      prompt: 'Prompt personalizado para la extracción', // Prompt personalizado opcional
      tag: 'production' // Etiqueta opcional para historiales de seguimiento de cambios por separado
    }
  ]
});

// Acceder a los cambios en formato git-diff
if (result.changeTracking.diff) {
  console.log(result.changeTracking.diff.text); // Texto de diff al estilo Git
  console.log(result.changeTracking.diff.json); // Datos de diff estructurados
}

// Acceder a los cambios de la comparación JSON
if (result.changeTracking.json) {
  console.log(result.changeTracking.json.title.previous); // Título anterior
  console.log(result.changeTracking.json.title.current); // Título actual
}
```

```python Python
result = firecrawl.scrape('https://example.com',
    formats=[
        'markdown',
        {
            'type': 'change_tracking',
            'modes': ['git-diff', 'json'],  # Habilita modos específicos de seguimiento de cambios
            'schema': {
                'type': 'object',
                'properties': {
                    'title': {'type': 'string'},
                    'content': {'type': 'string'}
                }
            },  # Esquema para la comparación de JSON estructurado
            'prompt': 'Prompt personalizado para la extracción',  # Prompt personalizado opcional
            'tag': 'production'  # Etiqueta opcional para historiales de seguimiento de cambios por separado
        }
    ]
)

# Acceder a los cambios en formato git-diff
if 'diff' in result.change_tracking:
    print(result.change_tracking.diff.text)  # Texto de diff al estilo Git
    print(result.change_tracking.diff.json)  # Datos de diff estructurados

# Acceder a los cambios de la comparación JSON
if 'json' in result.change_tracking:
    print(result.change_tracking.json.title.previous)  # Título anterior
    print(result.change_tracking.json.title.current)  # Título actual
```

</CodeGroup>

<CodeGroup>

```js Node
interface FirecrawlDocument {
  // ... other properties
  changeTracking?: {
    previousScrapeAt: string | null;
    changeStatus: "new" | "same" | "changed" | "removed";
    visibility: "visible" | "hidden";
    diff?: {
      text: string;
      json: {
        files: Array<{

  type: 'changeTracking';
  prompt?: string;
  schema?: any;
  modes?: ("json" | "git-diff")[];
  tag?: string | null;
}

interface ScrapeParams {
  // ... other properties
  formats?: Array<'markdown' | 'html' | ChangeTrackingFormat>;
}
```

```python Python
class ChangeTrackingData(BaseModel):
```

<div id="change-tracking-modes">
  ## Modos de Seguimiento de cambios
</div>

La función de Seguimiento de cambios admite dos modos:

<div id="git-diff-mode">
  ### Modo Git-Diff
</div>

El modo `git-diff` ofrece un formato de diff tradicional, similar a la salida de Git. Muestra los cambios línea por línea, con las adiciones y eliminaciones señaladas.

Ejemplo de salida:

```
@@ -1,1 +1,1 @@
-contenido anterior
+contenido nuevo
```

La representación JSON estructurada del diff incluye:

* `files`: Array de archivos modificados (en contexto web, normalmente solo uno)
* `chunks`: Secciones de cambios dentro de un archivo
* `changes`: Cambios de línea individuales con tipo (add, delete, normal)


<div id="json-mode">
  ### Modo JSON
</div>

El modo `json` ofrece una comparación estructurada de campos específicos extraídos del contenido. Esto es útil para hacer seguimiento de cambios en puntos de datos concretos en lugar de en todo el contenido.

Salida de ejemplo:

```json
{
  "title": {
    "previous": "Título anterior",
    "current": "Título nuevo"
  },
  "price": {
    "previous": "$19.99",
    "current": "$24.99"
  }
}
```

Para utilizar el modo JSON, debes proporcionar un esquema que defina los campos que se van a extraer y comparar.


<div id="important-facts">
  ## Datos importantes
</div>

A continuación, algunos detalles importantes que debes conocer al usar la función de Seguimiento de cambios:

- **Método de comparación**: Los raspados siempre se comparan a través de su respuesta en formato markdown.
  - El formato `markdown` también debe especificarse al usar el formato `changeTracking`. Además, se pueden especificar otros formatos.
  - El algoritmo de comparación es resistente a cambios en espacios en blanco y en el orden del contenido. Actualmente se ignoran las URL de origen de los iframes para resistir captchas y antibots con URL aleatorias.

- **Coincidencia con raspados anteriores**: Los raspados anteriores con los que comparar se asocian actualmente por la URL de origen, el ID del equipo, el formato `markdown` y el parámetro `tag`.
  - Para una comparación efectiva, la URL de entrada debe ser exactamente la misma que en la solicitud previa para el mismo contenido.
  - Rastrear las mismas URL con diferentes `includePaths`/`excludePaths` generará inconsistencias al usar `changeTracking`.
  - Raspar las mismas URL con diferentes `includeTags`/`excludeTags`/`onlyMainContent` generará inconsistencias al usar `changeTracking`.
  - Las páginas comparadas también se contrastarán con raspados anteriores que solo tengan el formato `markdown` sin el formato `changeTracking`.
  - Las comparaciones están limitadas a tu equipo. Si raspas una URL por primera vez con tu clave de API, su `changeStatus` siempre será `new`, incluso si otros usuarios de Firecrawl la han raspado antes.

- **Estado Beta**: Mientras esté en Beta, se recomienda monitorear el campo `warning` del documento resultante y contemplar que el objeto `changeTracking` pueda no estar presente en la respuesta.
  - Esto puede ocurrir si la consulta a la base de datos para encontrar el raspado anterior con el cual comparar excede el tiempo de espera.

<div id="tracking-product-price-changes">
  ### Seguimiento de cambios en el precio del producto
</div>

<CodeGroup>

```js Node
const result = await firecrawl.scrape('https://example.com/product', {
  formats: [
    'markdown',
    {
      type: 'changeTracking',
      modes: ['json'],
      schema: {
        type: 'object',
        properties: {
          price: { type: 'string' },
          availability: { type: 'string' }
        }
      }
    }
  ]
});

if (result.changeTracking.changeStatus === 'changed') {
  console.log(`El precio cambió de ${result.changeTracking.json.price.previous} a ${result.changeTracking.json.price.current}`);
}
```

```python Python
result = firecrawl.scrape('https://example.com/product',
    formats=[
        'markdown',
        {
            'type': 'change_tracking',
            'modes': ['json'],
            'schema': {
                'type': 'object',
                'properties': {
                    'price': {'type': 'string'},
                    'availability': {'type': 'string'}
                }
            }
        }
    ]
)

if result.change_tracking.change_status == 'changed':
    print(f"El precio cambió de {result.change_tracking.json.price.previous} a {result.change_tracking.json.price.current}")
```

</CodeGroup>

<div id="monitoring-content-changes-with-git-diff">
  ### Supervisión de cambios de contenido con Git-Diff
</div>

<CodeGroup>

```js Node
const result = await firecrawl.scrape('https://example.com/blog', {
  formats: [
    'markdown',
    { type: 'changeTracking', modes: ['git-diff'] }
  ]
});

if (result.changeTracking.changeStatus === 'changed') {
  console.log('Cambios en el contenido:');
  console.log(result.changeTracking.diff.text);
}
```

```python Python
result = firecrawl.scrape('https://example.com/blog',
    formats=[
        'markdown',
        { 'type': 'change_tracking', 'modes': ['git-diff'] }
    ]
)

if result.change_tracking.change_status == 'changed':
    print('Cambios en el contenido:')
    print(result.change_tracking.diff.text)
```

</CodeGroup>

<div id="billing">
  ## Facturación
</div>

La función de Seguimiento de cambios está actualmente en beta. Usar la funcionalidad básica de seguimiento de cambios y el modo `git-diff` no tiene costo adicional. Sin embargo, si usas el modo `json` para comparar datos estructurados, el raspado de la página costará 5 créditos por página.
