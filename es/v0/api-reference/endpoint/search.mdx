---
title: "Búsqueda (Beta)"
openapi: 'v0-openapi POST /search'
---

El endpoint de búsqueda combina una API de búsqueda con la potencia de Firecrawl para ofrecer una experiencia de búsqueda sólida para cualquier consulta. 

Busca automáticamente en la web la consulta y devuelve los resultados más relevantes de las páginas principales en formato Markdown. La ventaja de este endpoint es que raspa cada sitio web de los primeros resultados, por lo que siempre obtendrás el contenido completo.

Este endpoint está actualmente en beta y está sujeto a cambios.
