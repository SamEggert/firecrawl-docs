<div id="whats-new-in-v2">
  ## Novedades en la v2
</div>

<div id="tell-crawl-what-you-want">
  ### Indica al crawler lo que quieres
</div>

Describe qué rastrear en inglés sencillo:

```json
{
  "url": "https://example.com",
  "prompt": "Rastrea solo las entradas del blog y la documentación; omite las páginas de marketing"
}
```

Esto asociará el prompt con un conjunto de ajustes del crawler para ejecutar el rastreo.


<div id="improved-sitemap-control">
  ### Control mejorado del sitemap
</div>

En v1, el uso del sitemap era un valor booleano. En v2, la opción `sitemap` te permite elegir:

- `"include"` (por defecto): Usa el sitemap y también descubre otras páginas.
- `"skip"`: Ignora el sitemap por completo.

<div id="new-crawling-options">
  ### Nuevas opciones de rastreo
</div>

* `crawlEntireDomain` - Rastrear todo el dominio, no solo las páginas secundarias
* `maxDiscoveryDepth` - Controlar la profundidad del rastreo (sustituye a `maxDepth`)

```json
{
  "url": "https://example.com/features",
  "crawlEntireDomain": true,
  "maxDiscoveryDepth": 2,
  "sitemap": "include"
}
```
