</div>

Con Extract, puedes obtener fácilmente datos estructurados de cualquier URL. Debes especificar tu esquema en formato JSON Schema, usando la macro `serde_json::json!`.

<div id="crawling-a-website">
  ### Rastrear un sitio web
</div>

Para rastrear un sitio web, utiliza el método `crawl_url`. Este método esperará a que el rastreo finalice, lo que puede llevar mucho tiempo según la URL de inicio y las opciones que elijas.

<CrawlRustShort />

<div id="crawling-asynchronously">
  #### Rastreo asíncrono
</div>

Para rastrear sin esperar el resultado, usa el método `crawl_url_async`. Acepta los mismos parámetros, pero devuelve una estructura `CrawlAsyncRespone` que contiene el ID del rastreo. Puedes usar ese ID con el método `check_crawl_status` para consultar el estado en cualquier momento. Ten en cuenta que los rastreos completados se eliminan después de 24 horas.

<div id="error-handling">
  ## Manejo de errores
</div>

El SDK gestiona los errores que devuelve la API de Firecrawl y nuestras dependencias, y los unifica en el enum `FirecrawlError`, que implementa `Error`, `Debug` y `Display`. Todos nuestros métodos devuelven un `Result<T, FirecrawlError>`.
