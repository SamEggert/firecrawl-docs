Firecrawl ofrece diferentes tipos de proxy para ayudarte a extraer sitios web con distintos niveles de protección antibots. El tipo de proxy se puede especificar con el parámetro `proxy`.

> De forma predeterminada, Firecrawl enruta todas las solicitudes a través de proxies para garantizar la fiabilidad y el acceso, incluso si no especificas un tipo de proxy o una ubicación.

<div id="location-based-proxy-selection">
  ## Selección de proxy según la ubicación
</div>

Firecrawl selecciona automáticamente el mejor proxy según tu ubicación especificada o detectada. Esto ayuda a optimizar el rendimiento y la fiabilidad del raspado. Sin embargo, actualmente no todas las ubicaciones están admitidas. Las siguientes ubicaciones están disponibles:

| Country Code | Country Name         | Stealth Mode Support |
|--------------|----------------------|----------------------|
| AE           | United Arab Emirates | No                   |
| AU           | Australia            | No                   |
| BR           | Brazil               | Yes                  |
| CN           | China                | No                   |
| DE           | Germany              | Yes                  |
| FR           | France               | Yes                  |
| GB           | United Kingdom       | No                   |
| JP           | Japan                | No                   |
| QA           | Qatar                | No                   |
| TR           | Turkey               | No                   |
| US           | United States        | Yes                  |
| VN           | Vietnam              | No                   |

<Warning>La lista de ubicaciones de proxy admitidas se actualizó por última vez el 15 de mayo de 2025. La disponibilidad puede cambiar con el tiempo.</Warning>

Si necesitas proxies en una ubicación que no aparece arriba, [contáctanos](mailto:help@firecrawl.com) y cuéntanos tus requisitos.

Si no especificas un proxy o una ubicación, Firecrawl seleccionará automáticamente la mejor opción según el sitio de destino y tu solicitud.

<div id="how-to-specify-proxy-location">
  ## Cómo especificar la ubicación del proxy
</div>

Puedes solicitar una ubicación de proxy específica estableciendo el parámetro `location.country` en tu solicitud. Por ejemplo, para usar un proxy de Brasil, establece `location.country` en `BR`.

Para ver todos los detalles, consulta la [referencia de la API de `location.country`](https://docs.firecrawl.dev/api-reference/endpoint/scrape#body-location-country).

<div id="proxy-types">
  ## Tipos de proxy
</div>

Firecrawl admite tres tipos de proxy:

* **basic**: Proxy para extraer datos de sitios con poca o ninguna protección anti-bot. Es rápido y suele funcionar.
* **stealth**: Proxy sigiloso para extraer datos de sitios con protecciones anti-bot avanzadas o que bloquean proxies comunes. Es más lento, pero más confiable en ciertos sitios. [Más información sobre el Modo Stealth →](/es/features/stealth-mode)
* **auto**: Firecrawl reintentará automáticamente con proxy stealth si falla el proxy basic. Si el reintento con stealth tiene éxito, se cobrarán 5 créditos por el raspado. Si el primer intento con basic tiene éxito, solo se cobrará el costo regular.

***

> **Nota:** Para información detallada sobre el uso de proxies stealth, incluidos los costos en créditos y las estrategias de reintento, consulta la [documentación del Modo Stealth](/es/features/stealth-mode).
