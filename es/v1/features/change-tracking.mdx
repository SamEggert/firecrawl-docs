![Seguimiento de cambios](/images/launch-week/lw3d12.webp)

El seguimiento de cambios te permite supervisar y detectar cambios en el contenido web a lo largo del tiempo. Esta función está disponible tanto en los SDK de JavaScript como de Python.

<div id="overview">
  ## Descripción general
</div>

El Seguimiento de cambios te permite:

- Detectar si una página web ha cambiado desde el último raspado
- Ver los cambios específicos entre raspados
- Obtener datos estructurados sobre lo que ha cambiado
- Controlar la visibilidad de los cambios

Usando el formato `changeTracking`, puedes monitorear cambios en un sitio web y recibir información sobre:

- `previousScrapeAt`: La marca de tiempo del raspado previo con el que se compara la página actual (`null` si no hay raspado previo)
- `changeStatus`: El resultado de la comparación entre las dos versiones de la página
  - `new`: Esta página no existía o no se había descubierto antes (generalmente tiene `previousScrapeAt` en `null`)
  - `same`: El contenido de esta página no ha cambiado desde el último raspado
  - `changed`: El contenido de esta página ha cambiado desde el último raspado
  - `removed`: Esta página se eliminó desde el último raspado
- `visibility`: La visibilidad de la página/URL actual
  - `visible`: Esta página es visible, lo que significa que su URL se descubrió por una ruta orgánica (a través de enlaces en otras páginas visibles o del sitemap)
  - `hidden`: Esta página no es visible, lo que significa que aún está disponible en la web, pero ya no es detectable mediante el sitemap o el rastreo del sitio. Solo podemos identificar enlaces invisibles si antes habían sido visibles y se capturaron durante un rastreo o raspado previo

<div id="javascript-sdk">
  ## SDK para JavaScript
</div>

<div id="basic-usage">
  ### Uso básico
</div>

Para usar el Seguimiento de cambios en el SDK de JavaScript, incluye `'changeTracking'` en el array de formatos al raspar una URL:

```javascript
const app = new FirecrawlApp({ apiKey: 'your-api-key' });
const result = await app.scrapeUrl('https://example.com', {
  formats: ['markdown', 'changeTracking']
});

// Accede a los datos de Seguimiento de cambios
console.log(result.changeTracking.changeStatus); // 'nuevo', 'igual', 'modificado' o 'eliminado'
console.log(result.changeTracking.visibility); // 'visible' o 'oculto'
console.log(result.changeTracking.previousScrapeAt); // Marca de tiempo ISO del raspado anterior
```

Ejemplo de respuesta:

```json
{
  "url": "https://firecrawl.dev",
  "markdown": "# Agentes de IA para ofrecer grandes experiencias al cliente\n\nChatbots que encantan a tus usuarios...",
  "changeTracking": {
    "previousScrapeAt": "2025-04-10T12:00:00Z",
    "changeStatus": "modificado",
    "visibility": "visible"
  }
}
```


<div id="advanced-options">
  ### Opciones avanzadas
</div>

Puedes configurar el seguimiento de cambios con opciones adicionales:

```javascript
const result = await app.scrapeUrl('https://example.com', {
  formats: ['markdown', 'changeTracking'],
  changeTrackingOptions: {
    modes: ['git-diff', 'json'], // Habilita modos específicos de Seguimiento de cambios
    schema: { 
      type: 'object', 
      properties: { 
        title: { type: 'string' },
        content: { type: 'string' }
      } 
    }, // Esquema para la comparación de JSON estructurado
    prompt: 'Prompt personalizado para la extracción', // Prompt personalizado opcional
    tag: 'producción' // Etiqueta opcional para mantener historiales de seguimiento de cambios separados
  }
});

// Accede a los cambios en formato git-diff
if (result.changeTracking.diff) {
  console.log(result.changeTracking.diff.text); // Texto de diff al estilo Git
  console.log(result.changeTracking.diff.json); // Datos de diff estructurados
}

// Accede a los cambios de comparación JSON
if (result.changeTracking.json) {
  console.log(result.changeTracking.json.title.previous); // Título anterior
  console.log(result.changeTracking.json.title.current); // Título actual
}
```

<div id="python-sdk">
  ## SDK de Python
</div>

<div id="basic-usage">
  ### Uso básico
</div>

Para usar el Seguimiento de cambios en el SDK de Python, incluye &#39;changeTracking&#39; en la lista de formatos al raspar una URL:

```python
from firecrawl import FirecrawlApp, ChangeTrackingOptions

app = FirecrawlApp(api_key='your-api-key')
result = app.scrape_url('https://example.com',
    formats=['markdown', 'changeTracking']
)

# Accede a los datos de Seguimiento de cambios
print("Estado del cambio:", result.changeTracking.changeStatus)  # 'new', 'same', 'changed' o 'removed'
print("Visibilidad:", result.changeTracking.visibility)  # 'visible' o 'hidden'
print("Fecha del raspado anterior:", result.changeTracking.previousScrapeAt)  # Marca de tiempo ISO del raspado anterior
```


<div id="advanced-options">
  ### Opciones avanzadas
</div>

Puedes configurar el seguimiento de cambios con opciones adicionales:

```python
result = app.scrape_url('https://example.com',
    formats=['markdown', 'changeTracking'],
    change_tracking_options=ChangeTrackingOptions(
        modes=['git-diff', 'json'],  # Habilita modos específicos de Seguimiento de cambios
        schema={
            'type': 'object',
            'properties': {
                'title': {'type': 'string'},
                'content': {'type': 'string'}
            }
        },  # Esquema para la comparación JSON estructurada
        prompt='Indicaciones personalizadas para la extracción',  # Indicación personalizada opcional
        tag='production'  # Etiqueta opcional para mantener historiales de seguimiento de cambios separados
    )
)

# Acceder a los cambios en formato git-diff
if 'diff' in result.changeTracking:
    print(result.changeTracking.diff.text)  # Diff de texto al estilo Git
    print(result.changeTracking.diff.json)  # Datos de diff estructurados

# Acceder a los cambios de comparación JSON
if 'json' in result.changeTracking:
    print(result.changeTracking.json.title.previous)  # Título anterior
    print(result.changeTracking.json.title.current)  # Título actual
```

<div id="change-tracking-modes">
  ## Modos de seguimiento de cambios
</div>

La función de seguimiento de cambios admite dos modos:

<div id="git-diff-mode">
  ### Modo Git-Diff
</div>

El modo `git-diff` ofrece un formato de diff tradicional, similar a la salida de Git. Muestra los cambios línea por línea con las adiciones y eliminaciones señaladas.

Ejemplo de salida:

```
@@ -1,1 +1,1 @@
-contenido anterior
+contenido nuevo
```

La representación JSON estructurada del diff incluye:

* `files`: Lista de archivos modificados (en un contexto web, normalmente solo uno)
* `chunks`: Secciones de cambios dentro de un archivo
* `changes`: Cambios de línea individuales con tipo (add, delete, normal)


<div id="json-mode">
  ### Modo JSON
</div>

El modo `json` ofrece una comparación estructurada de campos específicos extraídos del contenido. Es útil para seguir cambios en puntos de datos concretos en lugar de en todo el contenido.

Salida de ejemplo:

```json
{
  "title": {
    "previous": "Título anterior",
    "current": "Título nuevo"
  },
  "price": {
    "previous": "$19.99",
    "current": "$24.99"
  }
}
```

Para usar el modo JSON, debes proporcionar un esquema que defina los campos que se deben extraer y comparar.


<div id="important-facts">
  ## Datos importantes
</div>

Estos son algunos detalles importantes que debes conocer al usar la función de Seguimiento de cambios:

- **Método de comparación**: Los raspados siempre se comparan mediante su respuesta en markdown.
  - El formato `markdown` también debe especificarse cuando se usa el formato `changeTracking`. Además, se pueden especificar otros formatos.
  - El algoritmo de comparación es resistente a cambios en espacios en blanco y en el orden del contenido. Actualmente se ignoran las URL de origen de iframes para ofrecer resistencia frente a captchas y antibots con URL aleatorias.

- **Coincidencia con raspados anteriores**: Los raspados anteriores contra los que se compara actualmente se asocian por la URL de origen, el ID del equipo, el formato `markdown` y el parámetro `tag`.
  - Para una comparación efectiva, la URL de entrada debe ser exactamente la misma que la solicitud anterior para el mismo contenido.
  - Rastrear las mismas URL con distintos `includePaths`/`excludePaths` presentará inconsistencias al usar `changeTracking`.
  - Raspar las mismas URL con distintos `includeTags`/`excludeTags`/`onlyMainContent` presentará inconsistencias al usar `changeTracking`.
  - Las páginas comparadas también se contrastarán con raspados anteriores que solo tengan el formato `markdown` sin el formato `changeTracking`.
  - Las comparaciones se limitan a tu equipo. Si raspas una URL por primera vez con tu clave de API, su `changeStatus` siempre será `new`, incluso si otros usuarios de Firecrawl ya la han raspado antes.

- **Estado Beta**: Mientras esté en Beta, se recomienda monitorear el campo `warning` del documento resultante y manejar la posible ausencia del objeto `changeTracking` en la respuesta.
  - Esto puede ocurrir cuando se agota el tiempo de la consulta a la base de datos para encontrar el raspado anterior con el cual comparar.

<div id="tracking-product-price-changes">
  ### Seguimiento de cambios en precios de productos
</div>

```javascript
// JavaScript
const result = await app.scrapeUrl('https://example.com/product', {
  formats: ['markdown', 'changeTracking'],
  changeTrackingOptions: {
    modes: ['json'],
    schema: {
      type: 'object',
      properties: {
        price: { type: 'string' },
        availability: { type: 'string' }
      }
    }
  }
});

if (result.changeTracking.changeStatus === 'changed') {
  console.log(`El precio cambió de ${result.changeTracking.json.price.previous} a ${result.changeTracking.json.price.current}`);
}
```

```python
# Python
result = app.scrape_url('https://example.com/product',
    formats=['markdown', 'changeTracking'],
    changeTrackingOptions={
        'modes': ['json'],
        'schema': {
            'type': 'object',
            'properties': {
                'price': {'type': 'string'},
                'availability': {'type': 'string'}
            }
        }
    }
)

if result.changeTracking.changeStatus == 'changed':
    print(f"El precio cambió de {result.changeTracking.json.price.previous} a {result.changeTracking.json.price.current}")
```


<div id="monitoring-content-changes-with-git-diff">
  ### Monitoreo de cambios de contenido con Git-Diff
</div>

```javascript
// JavaScript
const result = await app.scrapeUrl('https://example.com/blog', {
  formats: ['markdown', 'changeTracking'],
  changeTrackingOptions: {
    modes: ['git-diff']
  }
});

if (result.changeTracking.changeStatus === 'changed') {
  console.log('Cambios en el contenido:');
  console.log(result.changeTracking.diff.text);
}
```

```python
# Python
result = app.scrape_url('https://example.com/blog',
    formats=['markdown', 'changeTracking'],
    changeTrackingOptions={
        'modes': ['git-diff']
    }
)

if result.changeTracking.changeStatus == 'changed':
    print('Cambios en el contenido:')
    print(result.changeTracking.diff.text)
```


<div id="billing">
  ## Facturación
</div>

La función de Seguimiento de cambios está actualmente en beta. Usar la funcionalidad básica de seguimiento de cambios y el modo `git-diff` no tiene costo adicional. Sin embargo, si usas el modo `json` para la comparación de datos estructurados, el raspado de la página costará 5 créditos por página.
