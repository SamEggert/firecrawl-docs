El seguimiento de cambios es aún más potente cuando se combina con el crawling. Mientras que el seguimiento en páginas individuales muestra los cambios de contenido, usarlo con Crawl te permite monitorizar toda la estructura del sitio web, mostrando páginas nuevas, eliminadas y páginas que han pasado a estar ocultas.

<div id="basic-usage">
  ## Uso básico
</div>

Para habilitar el Seguimiento de cambios durante un rastreo, inclúyelo en el array `formats` de tus `scrapeOptions`:

```typescript
// JavaScript/TypeScript
const app = new FirecrawlApp({ apiKey: 'tu-api-key' });
const result = await app.crawl('https://example.com', {
  scrapeOptions: {
    formats: ['markdown', 'changeTracking']
  }
});
```

```python
# Python
app = FirecrawlApp(api_key='tu-api-key')
result = app.crawl('https://firecrawl.dev', {
    'scrapeOptions': {
        'formats': ['markdown', 'changeTracking']
    }
})
```

<div id="understanding-change-status">
  ## Entender el estado de cambios
</div>

Al usar el Seguimiento de cambios con crawl, el campo `changeStatus` resulta especialmente útil:

* `new`: Página que no existía en tu rastreo anterior
* `same`: Página que existe y no ha cambiado desde tu último rastreo
* `changed`: Página que existe pero se ha modificado desde tu último rastreo
* `removed`: Página que existía en tu rastreo anterior pero ya no se encuentra

<div id="page-visibility">
  ## Visibilidad de la página
</div>

El campo `visibility` te ayuda a entender cómo se descubren las páginas:

* `visible`: La página se puede encontrar a través de enlaces o del sitemap
* `hidden`: La página aún existe, pero ya no está enlazada ni aparece en el sitemap

Esto es especialmente útil para:

* Detectar contenido huérfano
* Encontrar páginas eliminadas accidentalmente de la navegación
* Supervisar cambios en la estructura del sitio
* Identificar contenido que debería volver a enlazarse o eliminarse
