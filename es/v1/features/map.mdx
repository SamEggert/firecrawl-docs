<div id="introducing-map">
  ## Presentamos /map
</div>

La forma más sencilla de convertir una sola URL en un mapa de todo el sitio web. Es especialmente útil para:

- Cuando necesitas solicitar al usuario final que elija qué enlaces raspar
- Cuando necesitas conocer rápidamente los enlaces de un sitio web
- Cuando necesitas raspar páginas de un sitio web relacionadas con un tema específico (usa el parámetro `search`)
- Cuando solo necesitas raspar páginas específicas de un sitio web

<div id="map-with-search">
  #### Mapa con búsqueda
</div>

El endpoint Mapa con el parámetro `search` te permite buscar URLs específicas dentro de un sitio web.

```bash cURL
curl -X POST https://api.firecrawl.dev/v1/map \
    -H 'Content-Type: application/json' \
    -H 'Authorization: Bearer TU_CLAVE_API' \
    -d '{
      "url": "https://firecrawl.dev",
      "search": "docs"
    }'
```

La respuesta será una lista ordenada de la más relevante a la menos relevante.

```json
{
  "status": "success",
  "links": [
    "https://docs.firecrawl.dev",
    "https://docs.firecrawl.dev/sdks/python",
    "https://docs.firecrawl.dev/learn/rag-llama3",
  ]
}
```


<div id="considerations">
  ## Consideraciones
</div>
