Firecrawl ofrece distintos tipos de proxy para ayudarte a extraer sitios web con distintos niveles de protección antibots. El tipo de proxy puede especificarse con el parámetro `proxy`.


<div id="proxy-types">
  ### Tipos de proxy
</div>

Firecrawl admite tres tipos de proxy:

- **basic**: Proxy para extraer sitios con nulas o básicas soluciones anti‑bot. Rápido y suele funcionar.
- **stealth**: Proxy sigiloso para extraer sitios con soluciones anti‑bot avanzadas. Más lento, pero más fiable en ciertos sitios.
- **auto**: Firecrawl reintentará automáticamente la extracción con proxies stealth si falla el proxy basic. Si el reintento con stealth tiene éxito, se cobrarán 5 créditos por la extracción. Si el primer intento con basic tiene éxito, solo se cobrará el costo normal.

Si no especificas un proxy, Firecrawl usará basic de forma predeterminada.

  ## Usar el modo stealth como mecanismo de reintento
