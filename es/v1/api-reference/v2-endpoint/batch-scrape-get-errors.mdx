<div id="whats-new-in-v2">
  ## Novedades de v2
</div>

<div id="better-batch-error-messages">
  ### Mejores mensajes de error en Raspado por lotes
</div>

- Errores claros para problemas de procesamiento de formato en todas las URL
- Mensajes específicos para fallos de PDF y de parsers
- Mejor seguimiento de errores para distintos modos de proxy
- Errores claros para problemas de raspado según la ubicación

<div id="more-error-details">
  ### Más detalles de error
</div>

- Información de depuración para problemas de Seguimiento de cambios
- Informe de errores para fallas en la automatización del navegador
- Mejor seguimiento de errores de crédito y límites de recursos
- Errores específicos para problemas de procesamiento por lotes

<div id="faster-and-easier-debugging">
  ### Depuración más rápida y sencilla
</div>

- Obtención de errores más rápida en lotes grandes
- Mejor agrupación de errores
- Contexto de errores más útil

La misma API que en v1, pero con informes de errores mucho mejores para las funciones de v2 en lotes.
