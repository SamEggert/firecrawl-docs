<div id="whats-new-in-v2">
  ## Novedades en v2
</div>

<div id="tell-the-crawler-what-you-want">
  ### Indícale al Crawler lo que quieres
</div>

Describe en lenguaje sencillo qué debe rastrear:

```json
{
  "url": "https://example.com",
  "prompt": "Rastrea solo las publicaciones del blog y la documentación; omite las páginas de marketing"
}
```


<div id="better-sitemap-control">
  ### Mejor control del sitemap
</div>

v1: activado/desactivado para sitemaps. v2: tres opciones:

- `"include"` - Usar el sitemap + encontrar otras páginas (predeterminado)
- `"skip"` - Ignorar el sitemap por completo  
- `"only"` - Rastrear únicamente las URL del sitemap

<div id="new-crawling-options">
  ### Nuevas opciones de rastreo
</div>

* `crawlEntireDomain` - Rastrea todo el dominio, no solo las páginas secundarias
* `maxDiscoveryDepth` - Controla la profundidad del rastreo (reemplaza `maxDepth`)

```json
{
  "url": "https://example.com/features",
  "crawlEntireDomain": true,
  "maxDiscoveryDepth": 2,
  "sitemap": "include"
}
```
