<div id="whats-new-in-v2">
  ## Novedades en v2
</div>

<div id="search-multiple-sources">
  ### Buscar en múltiples fuentes
</div>

Busca web, imágenes y noticias a la vez:

```json
{
  "query": "firecrawl web scraping",
  "sources": [
    {"type": "web", "tbs": "qdr:w", "location": "US"},
    {"type": "images"},
    {"type": "news"}
  ]
}
```


<div id="response-format-changed">
  ### Se cambió el formato de la respuesta
</div>

v1: lista plana de resultados. v2: organizado por tipo de origen:

```json
{
  "success": true,
  "data": {
    "web": [/* resultados de la web */],
    "images": [/* resultados de imágenes */],
    "news": [/* resultados de noticias */]
  }
}
```


<div id="new-features">
  ### Nuevas funciones
</div>

- Filtrar por rangos de tiempo ("past week", "past month")
- Orientar a países o regiones específicos
- Resultados limitados a 500 durante la fase alfa

El endpoint de búsqueda combina la búsqueda web (SERP) con las capacidades de raspado de Firecrawl para devolver el contenido completo de la página para cualquier consulta.

Incluye `scrapeOptions` con `formats: [{"type": "markdown"}]` para obtener el contenido completo en markdown de cada resultado de búsqueda; de lo contrario, por defecto recibirás los resultados del SERP (url, title, description). También puedes usar otros formatos como `{"type": "summary"}` para contenido condensado.

<div id="supported-query-operators">
  ## Operadores de consulta compatibles
</div>

Ofrecemos una variedad de operadores de consulta que te permiten filtrar mejor tus búsquedas.

| Operador | Funcionalidad | Ejemplos |
---|-|-|
| `""` | Coincidencia exacta con una cadena de texto | `"Firecrawl"`
| `-` | Excluye ciertas palabras clave o niega otros operadores | `-bad`, `-site:firecrawl.dev`
| `site:` | Devuelve solo resultados de un sitio web especificado | `site:firecrawl.dev`
| `inurl:` | Devuelve solo resultados que incluyan una palabra en la URL | `inurl:firecrawl`
| `allinurl:` | Devuelve solo resultados que incluyan varias palabras en la URL | `allinurl:git firecrawl`
| `intitle:` | Devuelve solo resultados que incluyan una palabra en el título de la página | `intitle:Firecrawl`
| `allintitle:` | Devuelve solo resultados que incluyan varias palabras en el título de la página | `allintitle:firecrawl playground`
| `related:` | Devuelve solo resultados relacionados con un dominio específico | `related:firecrawl.dev`

<div id="location-parameter">
  ## Parámetro de ubicación
</div>

Usa el parámetro `location` para obtener resultados de búsqueda segmentados por ubicación. Formato: `"string"`. Ejemplos: `"Germany"`, `"San Francisco,California,United States"`.

Consulta la [lista completa de ubicaciones compatibles](https://firecrawl.dev/search_locations.json) para ver todos los países e idiomas disponibles.

<div id="time-based-search">
  ## Búsqueda por tiempo
</div>

Usa el parámetro `tbs` para filtrar los resultados por periodos de tiempo, incluidos rangos de fechas personalizados. Consulta la [documentación de la función Búsqueda](https://docs.firecrawl.dev/features/search#time-based-search) para ver ejemplos detallados y formatos admitidos.
