<div id="whats-new-in-v2">
  ## Novedades en v2
</div>

<div id="better-error-messages">
  ### Mejores mensajes de error
</div>

- Errores claros cuando las indicaciones en lenguaje natural no funcionan
- Mensajes específicos para problemas con el sitemap y con los límites de profundidad
- Mensajes más precisos para problemas de rastreo a nivel de dominio

<div id="more-error-details">
  ### Más detalles de errores
</div>

- Errores detallados para problemas de procesamiento de formatos
- Mensajes específicos para fallos de PDF y de parsers
- Mejor depuración para el rastreo basado en ubicación
- Errores claros para problemas de seguimiento de cambios

<div id="faster-and-easier-debugging">
  ### Depuración más rápida y sencilla
</div>

- Obtención de errores más ágil en rastreos grandes
- Mejor agrupación de errores
- Contexto de errores más útil

La misma API que en v1, con informes de errores mucho mejores para las funciones de v2.
