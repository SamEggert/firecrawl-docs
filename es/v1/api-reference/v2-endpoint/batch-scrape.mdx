<div id="whats-new-in-v2">
  ## Novedades en la v2
</div>

<div id="all-new-formats-work-in-batches">
  ### Todos los formatos nuevos funcionan en lotes
</div>

- Usa capturas de pantalla personalizadas, extracción en JSON y seguimiento de cambios en todas las URL
- Procesa PDF en lotes con el nuevo sistema de parsers
- Aplica la misma configuración de formato a cada URL del lote

<div id="better-batch-processing">
  ### Mejor procesamiento por lotes
</div>

- Raspado desde diferentes países/idiomas para lotes completos
- Usa modos de proxy stealth, basic o auto en todas las URL
- Todas las nuevas opciones de raspado funcionan en modo por lotes

<div id="faster-and-more-reliable">
  ### Más rápido y más fiable
</div>

- Mejor gestión de recursos para lotes complejos
- Seguimiento del progreso mejorado
- Mejor manejo de errores

La misma API que en v1; todas las funciones de v2 funcionan en todo el lote.
