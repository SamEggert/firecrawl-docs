<div id="whats-new-in-v2">
  ## Novedades en v2
</div>

La API para cancelar Raspado por lotes en v2 mantiene la misma funcionalidad que v1, con mayor confiabilidad:

<div id="enhanced-cancellation-process">
  ### Proceso de cancelación mejorado
</div>

- Mejoras en la limpieza y la gestión de recursos para operaciones por lotes
- Mejor manejo de la finalización de lotes activos
- Mejor manejo de errores en operaciones de cancelación de lotes

Los parámetros de la API y el formato de respuesta se mantienen sin cambios desde v1, lo que garantiza una migración fluida y una cancelación por lotes más confiable.
