<div id="how-it-works">
  ## Cómo funciona
</div>

Usa las capacidades de extracción de Firecrawl para crear sistemas de observabilidad para tus sitios web. Extrae el contenido de las páginas, analiza los cambios a lo largo del tiempo, valida las publicaciones y crea flujos de monitoreo que garanticen que tus sitios funcionen correctamente.

<div id="what-you-can-monitor">
  ## Qué puedes monitorizar
</div>

* **Disponibilidad**: Tiempo de actividad, tiempos de respuesta, tasas de error
* **Contenido**: Cambios de texto, actualizaciones de imágenes, cambios de diseño
* **Rendimiento**: Tiempos de carga de la página, tamaños de recursos, Core Web Vitals
* **Seguridad**: Certificados SSL, cabeceras de seguridad, configuraciones incorrectas
* **Salud de SEO**: Metadatos, datos estructurados, validez del sitemap

<div id="faqs">
  ## Preguntas frecuentes
</div>

<AccordionGroup>
  <Accordion title="¿Cómo ayuda Firecrawl con la supervisión de sitios web?">
    Firecrawl extrae el contenido y la estructura de los sitios web bajo demanda. Crea sistemas de supervisión que llamen a la API de Firecrawl para revisar páginas, comparar los datos extraídos con bases de referencia y activar tus propias alertas cuando haya cambios.
  </Accordion>

  <Accordion title="¿Puedo supervisar aplicaciones con mucho JavaScript?">
    ¡Sí! Firecrawl renderiza completamente JavaScript, lo que lo hace ideal para supervisar SPAs modernas, aplicaciones React y contenido dinámico. Capturamos la página tal como la ven los usuarios, no solo el HTML sin procesar.
  </Accordion>

  <Accordion title="¿Con qué rapidez puedo detectar problemas en un sitio web?">
    Firecrawl extrae datos en tiempo real cuando se le invoca. Diseña tu sistema de supervisión para revisar sitios con la frecuencia que necesites: desde minuto a minuto para páginas críticas hasta diariamente para verificaciones rutinarias.
  </Accordion>

  <Accordion title="¿Puedo validar elementos específicos de la página?">
    Sí. Usa la API de Extract (/v2/extract) para obtener elementos específicos como precios, niveles de inventario o contenido crítico. Crea lógica de validación en tu sistema de supervisión para verificar que la información importante esté presente y sea correcta.
  </Accordion>

  <Accordion title="¿Cómo puedo integrar Firecrawl con sistemas de alertas?">
    Firecrawl proporciona webhooks que puedes usar para crear integraciones con tus herramientas de alertas. Envía los datos extraídos a PagerDuty, Slack, correo electrónico o cualquier plataforma de supervisión mediante conectores que procesen las respuestas de Firecrawl.
  </Accordion>
</AccordionGroup>
