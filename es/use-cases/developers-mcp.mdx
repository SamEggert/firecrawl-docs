</div>

Integra Firecrawl directamente en tu flujo de trabajo de desarrollo de IA. Investiga documentación, obtiene especificaciones de API y accede a datos web sin salir de tu entorno de desarrollo mediante Model Context Protocol.

<div id="build-smarter-ai-assistants">

<div id="faqs">
  ## Preguntas frecuentes
</div>

<AccordionGroup>
  <Accordion title="¿Qué asistentes de IA son compatibles con MCP?">
    Actualmente, Claude Desktop y Cursor tienen compatibilidad nativa con MCP. Cada vez más asistentes de IA añaden soporte. También puedes usar el SDK de MCP para crear integraciones personalizadas.
  </Accordion>

  <Accordion title="¿Puedo usar MCP en VS Code u otros IDE?">
    VS Code y otros IDE pueden usar MCP mediante extensiones de la comunidad o integraciones por terminal. La compatibilidad nativa varía según el IDE. Consulta nuestro [repositorio de GitHub](https://github.com/mendableai/firecrawl-mcp-server) para guías de configuración específicas por IDE.
  </Accordion>

  <Accordion title="¿Cómo puedo cachear documentos de acceso frecuente?">
    El servidor MCP almacena automáticamente en caché las respuestas durante 15 minutos. Puedes configurar la duración de la caché en la configuración de tu servidor MCP o implementar lógica de caché personalizada.
  </Accordion>

  <Accordion title="¿Existe un límite de tasa para las solicitudes de MCP?">
    Las solicitudes de MCP usan tus límites de tasa estándar de la API de Firecrawl. Recomendamos agrupar solicitudes relacionadas y usar caché para la documentación de acceso frecuente.
  </Accordion>

  <Accordion title="¿Cómo configuro MCP con mi clave de API de Firecrawl?">
    Sigue nuestra [guía de instalación](https://github.com/mendableai/firecrawl-mcp-server#installation) para configurar MCP. Necesitarás añadir tu clave de API de Firecrawl a tu archivo de configuración de MCP. El proceso lleva solo unos minutos.
  </Accordion>
</AccordionGroup>
