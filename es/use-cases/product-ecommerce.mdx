<div id="how-it-works">
  ## Cómo funciona
</div>

Convierte sitios web de comercio electrónico en datos de productos estructurados. Supervisa los precios de la competencia en tiempo real, controla los niveles de inventario entre proveedores y migra catálogos de productos entre plataformas sin complicaciones.

<div id="what-you-can-extract">
  ## Qué puedes extraer
</div>

* **Datos de producto**: Título, SKU, especificaciones, descripciones, categorías
* **Precios**: Precio actual, descuentos, envío, impuestos
* **Inventario**: Niveles de existencias, disponibilidad, plazos de entrega
* **Reseñas**: Valoraciones, comentarios de clientes, secciones de preguntas y respuestas

<div id="faqs">
  ## Preguntas frecuentes
</div>

<AccordionGroup>
  <Accordion title="¿Cómo puedo hacer seguimiento de cambios en los precios de la competencia?">
    Construya un sistema de monitoreo con la API de Firecrawl para extraer precios a intervalos regulares. Compare los datos extraídos a lo largo del tiempo para identificar tendencias, promociones y el posicionamiento frente a la competencia.
  </Accordion>

  <Accordion title="¿Puedo extraer variantes de producto (talla, color, etc.)?">
    Sí, Firecrawl puede extraer todas las variantes de un producto, incluidas la talla, el color y otras opciones. Estructure los datos con esquemas personalizados para capturar toda la información de las variantes.
  </Accordion>

  <Accordion title="¿Cómo manejo precios dinámicos o específicos para cada usuario?">
    Para precios dinámicos, puede usar el renderizado de JavaScript de Firecrawl para capturar los precios después de que se carguen. Para precios específicos por usuario, configure los encabezados de autenticación en sus solicitudes.
  </Accordion>

  <Accordion title="¿Puedo extraer datos de diferentes plataformas de comercio electrónico?">
    Sí. Firecrawl puede extraer datos de cualquier sitio web de comercio electrónico de acceso público. Los usuarios extraen con éxito de Shopify, WooCommerce, Magento, BigCommerce y tiendas a medida.
  </Accordion>

  <Accordion title="¿Puede Firecrawl manejar la paginación y el scroll infinito?">
    Sí. Firecrawl puede navegar por listados de productos paginados y manejar mecanismos de scroll infinito para extraer catálogos de productos completos, asegurando que no se omitan productos durante la extracción.
  </Accordion>
</AccordionGroup>
