<div id="sync-web-data-in-langflow-workflows">
  ## Sincroniza datos web en flujos de trabajo de Langflow
</div>

Firecrawl puede utilizarse dentro de [Langflow, el constructor de flujos de trabajo de IA](https://www.langflow.org/). Esta página explica cómo configurar y usar un bloque de Firecrawl en Langflow.

<div id="scraping-with-firecrawl-blocks">
  ### Raspado con bloques de Firecrawl
</div>

1. Inicia sesión en tu cuenta de Firecrawl y obtén tu API Key; luego introdúcela en el bloque o pásala desde otra parte del flujo de trabajo.
2. (Opcional) Conecta Text Splitter.
3. Selecciona el modo de raspado para capturar una sola página.
4. Introduce la URL de destino que se va a raspar o pásala desde otra parte del flujo de trabajo.
5. Configura las Page Options y Extractor Options según el sitio web y los datos que necesitas. También puedes pasarlas desde otra parte del flujo de trabajo.
6. Utiliza los datos en tus flujos de trabajo.
